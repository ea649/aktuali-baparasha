# אקטואלי בפרשה — שלהבות חב"ד

אתר חומרי פרשת השבוע למורות: עמוד ראשי עם כל הנושאים, ודף לכל נושא עם הצגה בכיתה (מסך מלא) והורדה להדפסה.

## עדכון שבועי
1. מייצאים מקנבה את החומרים החדשים ושומרים אותם ב-`assets/m` באותם שמות קבצים (תמונות העמודים בפורמט webp, וקובץ PDF לכל נושא).
2. מעדכנים ב-`assets/data.js` את שם הפרשה (`parasha`), ואם צריך גם את המשפטים במשחק, את שאלות הראיון ואת קישור הסרטון של פרשה LIVE (`video`).
3. שומרים ומעלים לגיטהב — האתר מתעדכן לבד תוך דקה-שתיים.

| נושא | קובץ |
|---|---|
| פגישה עם הפרשה | `pgisha.html` |
| פרשה PLAY | `play.html` |
| פרשה LIVE | `live.html` |
| אלוף הפרשה | `aluf.html` |
| פרשה פודקאסט | `podcast.html` |
| טדברו בבית | `ted.html` |
