# אקטואלי בפרשה — שלהבות חב"ד

אתר חומרי פרשת השבוע למורות: עמוד ראשי עם כל הנושאים, ודף לכל נושא עם הצגה בכיתה (מסך מלא) והורדה להדפסה.

## עדכון שבועי
הפרשה באתר מתחלפת לבד בכל יום ראשון לפרשה של השבת הקרובה (לוח ארץ ישראל). המורות יכולות לעבור בין פרשות בחיצים, או בזכוכית המגדלת שפותחת את רשימת כל הפרשות עם חיפוש.

כדי להוסיף את החומרים של פרשה — מוסיפים תיקייה אחת, ולא נוגעים בשום קובץ אחר:
1. מוצאים את מזהה הפרשה ב-`assets/parashot.js` (למשל `lech-lecha`, `vayera`, `nitzavim--vayeilech`).
2. יוצרים את התיקייה `assets/p/<מזהה הפרשה>/` ובה תמונות העמודים (webp/png/jpg), קובץ PDF לכל נושא,
   וקובץ `materials.json` שמתאר אותם (דוגמה: `assets/p/nitzavim--vayeilech/materials.json`).
   נושא שלא מופיע ב-materials.json — מופיע באתר כ"בקרוב".
3. מעלים את התיקייה לגיטהב — האתר מתעדכן לבד תוך דקה-שתיים.

את כל התהליך אפשר לתת לצ'אט: הקובץ `הוראות לצ'אט - אקטואלי בפרשה.md` מסביר לו בדיוק מה לעשות.

לוח הפרשות מגיע עד ספטמבר 2031. כדי להאריך: `node tools/make-parashot.mjs 5792 6`.

## עיצוב
- **גופן:** Fb Matritsa — אותו גופן של העיצובים בקנבה (`assets/fonts`).
- **אייקונים:** אייקונים תלת־ממדיים ב-`assets/icons` (נוצרו ב-OpenAI, הסקריפט: `tools/make-icons.mjs`).
- **עמוד הבית:** לוח אחד שנכנס במסך בלי גלילה, באותה חלוקה כמו "אקטואלי בפרשה" בקנבה. כל כרטיס לחיץ.
- **בדיקה מקומית:** `node tools/serve.mjs` ואז http://localhost:8080
